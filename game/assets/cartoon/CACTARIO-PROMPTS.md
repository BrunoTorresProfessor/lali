# Cactário — produção visual

Gerado com a ferramenta integrada ImageGen a partir das seis fotos enviadas. Os cinco cenários foram adaptados para formato horizontal, seguindo o estilo de `bromeliario-unificado.png`.

O arquivo de Thiago foi entregue pela ferramenta em RGB, com fundo quadriculado. A fase aplica uma máscara de silhueta nativa do Phaser para mostrar o personagem recortado sobre os cenários, preservando a imagem original. Uma tentativa adicional de extração de fundo pela ferramenta também retornou RGB e não foi usada.
